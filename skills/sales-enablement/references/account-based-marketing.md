# Account-Based Marketing

Apply the [shared operating contract](../../cmo/references/operating-contract.md). Use [Business Model Strategy](../../business-model-strategy/SKILL.md) to adapt goals and economics when context is missing.

Apply this reference through the owning skill; it is not a separate installed skill.

## Workflow

1. Agree target-account tiers and selection evidence with the business; distinguish named account fit from assumed purchase intent.
2. Map buying roles, procurement/security/business concerns, influence and stage with verified evidence; do not invent named stakeholders or relationship access.
3. Build one-to-one, one-to-few or one-to-many plays according to value, account count and capacity, combining useful content, outbound, ads, partners and events.
4. Create account-specific messages and proof assets for each role, a coordinated contact plan and sales-owner handoffs.
5. Use available CRM/account fields for suppression, stage and touch coordination; treat setup changes and advertising audiences as separately authorized writes.
6. Measure account coverage, meaningful engagement, qualified opportunity creation, stage progression and won value over the real sales cycle; views are not revenue.

## Deliverable

Tiered account plan, buying-group map, role-specific assets, coordinated playbook and pipeline review.

Read the [working reference](account-based-marketing-workflow.md) for relevant variants, fields and handoffs. For connected work, use [CLI capability checks](../../cli-integrations/references/tool-capabilities.md); no CLI or MCP is bundled.
