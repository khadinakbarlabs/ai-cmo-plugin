# Marketing to Sales Handoff

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

For prospect qualification, use bounded rows supplied inline and start directly with [Lead Generation](references/lead-generation.md) and its [import contract](references/lead-import.md); skip the case-study workflow below. File-opening import procedures are disabled for this directory edition; retain them as manual handoff formats only. For outreach drafts use [Outbound Marketing](references/outbound-marketing.md); sending remains a separate authorized operation.

## Workflow

1. Define customer fit, buying stage and evidence sales needs to advance the conversation.
2. Create qualification criteria and routing rules using actual available CRM fields.
3. Write case studies, objection responses and battlecards grounded in verified customer/competitive evidence.
4. Respect consent for named customer quotes and outcomes; otherwise anonymize or use approved evidence.
5. Deliver the handoff pack with ownership, response timing and pipeline metrics; do not autonomously negotiate contracts.

## Deliverable

Battlecard, case study/advocacy brief, qualification and lead handoff specification.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

## Specialized workflow routes

Choose the relevant guide before performing that task; retain its evidence, authority and acceptance checks.

- [Lead Generation](references/lead-generation.md): ICP and qualification rubric, source-linked prospect sheet, capture assets, routing rules and pipeline measurement plan.
- [Outbound Marketing](references/outbound-marketing.md): Qualified account list, evidence-backed outreach sequence, suppression/contact rules and meeting/pipeline scorecard.
- [Account-Based Marketing](references/account-based-marketing.md): Tiered account plan, buying-group map, role-specific assets, coordinated playbook and pipeline review.
