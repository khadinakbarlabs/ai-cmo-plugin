# Shortest marketing route

Inspect the user's supplied content and current business/campaign first. Do not open every department or create a new brief for a narrow request. These are routes through existing public skill IDs, not new commands or executable dispatch rules.

| Request | Owner / first useful result | Boundary |
| --- | --- | --- |
| Build a marketing plan; choose our channels | cmo → recommendation, calendar and requested reviewed assets | Adapt to actual conversion; no fabricated baseline |
| Fix this headline / improve a landing-page paragraph | copywriting → corrected editable copy | Preserve confirmed offer; no account processing or strategy reset |
| Audit conversions / paid campaigns / technical SEO | conversion-audit / paid-media / technical-seo → evidence-linked findings and affected fix | Keep defect scope; implementations use the actual site/account tools and authority |
| Find keywords / backlink opportunities / competitor ads | keyword-research / link-building / ad-research → scoped evidence and priorities | No unsupported volumes, profitability or access circumvention |
| Import this prospect CSV and qualify companies | sales-enablement → lead-generation guide → traceable account sheet | Company-first; contact lookup optional; no login or Actor launch |
| Collect this existing Actor run | apify-research → bounded paging and receipt | A run ID is not authority to create another paid run |
| Create ad variants / article / newsletter | ad-creation / content-production / newsletter-editorial → actual drafts | Titles and production instructions alone are incomplete |
| Review these brand claims / calculate our marketing KPIs | brand-strategy / marketing-analytics → claim ledger / calculated report | A deterministic calculation cannot establish factual or semantic truth |
| Publish these approved posts | social-publishing → verify destination, exact content, timing and authority | Reconcile ambiguous creates before retry; do not infer publish from draft |
| Continue our campaign | cmo → existing task board and next relevant specialist | Reuse accepted decisions/artifacts; repair invalid state; refresh stale evidence |
| Review results weekly | marketing-operations → supported scheduler receipt or draft handoff | Explicit scope, expiry and activation readback; no bundled scheduler |

“Build a browser extension,” “fix our payment API,” and “humanize this text with Humanizer PRO” belong to their product workflows. AI CMO can provide a marketing handoff when requested; it must not take over app engineering or trigger paid text processing. Generic “continue” without a known marketing task needs the relevant project context before selection.

For an import or local draft, start with the supplied file/material. Ask only for missing facts that change the dependent action, while doing useful independent work. If a tool is absent or access is denied, finish the supported local output and name one precise blocked operation.
