# Creative Production working reference

## Output contract

Production brief, shot list, creator scripts and permitted design-only visual aids; video/audio generation is unsupported.

Record the business/campaign ID, source dates and input scope. Include the useful artifact plus evidence, unavailable fields, decision and next owner. Treat an estimated outcome as a hypothesis until measured.

## Quality checks

- Does the output answer the requested customer/business job?
- Can another person verify the important facts from the retained evidence?
- Are prerequisites and actual tool capabilities distinguished from completed actions?
- Are unknown metrics marked and recommendations tied to a test or evidence?
- Is the next handoff concrete and editable?

## Recovery

For missing tools or accounts, produce the useful draft/import-based result and identify the specific missing capability. For empty data, retain collection scope and explain the absence rather than inventing a finding. For partial results, mark the missing portion and avoid extrapolating to the whole market.

## Production gates

Brief: message, audience, aspect ratio, safe areas, duration, script, shot list, sound/voice, captions, CTA, required product/brand assets and provider cost scope. Preview: inspect the actual file for temporal continuity, readable text, correct crop, audio clipping, alignment and claim accuracy. Final: confirm dimensions, format, size, duration and accessible output path. A generation API success or an unavailable remote URL is not visual QA. For UGC specify disclosure/rights and genuine product demonstration; never impersonate an actual customer.

## Covered variants

- Static ad design briefs
- Design-only visual aid production
- Video ad scripts
- Video production handoff (no generation)
- UGC and creator briefs

## Optional external CLI

Use the retained [media handoff reference](../../cli-integrations/references/agent-media-cli.md). This release does not launch a media generation CLI.

## Cross-channel and localized assets

Specify text, static/design, short/long video, audio/podcast, presentations, sales collateral, print/field or other requested format. Adapt accessibility, language, audience/culture, distribution rights and actual destination requirements. Transcreation needs claim/meaning review in each locale. Apply the [directory boundaries](../../cmo/references/directory-boundaries.md): no AI video/audio/voice or general-purpose image generation; a brief or preview must not be reported as a finished verified asset.
