# Newsletter Editorial

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Define the audience promise and the job this issue helps readers accomplish.
2. Select a coherent angle supported by useful evidence rather than a disconnected link roundup.
3. Write the issue, subject/preheader variants and one clear CTA; disclose commercial relationships where relevant.
4. Review reader value, voice, links, repetition and accessibility.
5. Prepare a sending handoff or authorized provider request; measure engagement with known tracking limitations.

## Deliverable

Newsletter draft, subject/preheader alternatives, link checks and measurement notes.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.
