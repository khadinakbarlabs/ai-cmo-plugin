# Inbound and Demand Generation

Apply the [shared operating contract](../../cmo/references/operating-contract.md). Use [Business Model Strategy](../../business-model-strategy/SKILL.md) to adapt goals and economics when context is missing.

Apply this reference through the owning skill; it is not a separate installed skill.

## Workflow

1. Map buyer questions, awareness, intent, objections and the buying journey for the actual business model.
2. Choose helpful owned assets and discovery routes: content, SEO/AI search, social, newsletter, community, webinars or partners; separate demand creation from existing demand capture.
3. Build an offer-to-content-to-conversion map with useful ungated/gated choices; match capture friction to value and trust.
4. Produce a flagship asset brief, supporting distribution, a conversion page and a nurture handoff; do not stop at an editorial calendar.
5. Align marketing and sales definitions, ownership and response expectations for high-consideration journeys; use retention/activation for self-service models.
6. Assess qualified demand and cohort/pipeline outcomes rather than reach alone; adapt timing to the purchase cycle and state attribution limits.

## Deliverable

Inbound journey, asset/distribution plan, capture/nurture pack and qualified-demand measurement.

Read the [working reference](inbound-marketing-workflow.md) for relevant variants, fields and handoffs. For connected work, use [CLI capability checks](../../cli-integrations/references/tool-capabilities.md); no CLI or MCP is bundled.
