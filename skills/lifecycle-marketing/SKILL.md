# Lifecycle Marketing

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Define lifecycle stages, events and desired behavior from actual product/business context.
2. Map entry/exit, delays, suppression and overlap rules; do not invent available events.
3. Draft messages tailored to the user job and stage, including cart recovery, onboarding or renewal as appropriate.
4. Design CRM routing and handoffs using aggregate data; minimize personal record exports.
5. Specify trigger verification, sequence testing and outcome metrics before any authorized automation deployment.

## Deliverable

Journey map, message sequence, trigger/suppression rules and implementation/test brief.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

For account or production tools, use [CLI Integrations](../cli-integrations/SKILL.md) and its [tool capability guide](../cli-integrations/references/tool-capabilities.md). Do not assume an external CLI is installed or supports the intended action.
