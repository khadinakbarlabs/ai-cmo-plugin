# Partnerships and Referrals

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Define the customer value, partner fit and economic constraints.
2. Research relevant partners using owned search/contact tools; retain source and qualification.
3. Design incentives, attribution, eligibility, anti-abuse checks and payout handoffs without creating commitments.
4. Prepare co-marketing, referral or affiliate assets and a pilot proposal.
5. Track partner-sourced outcomes and costs; contracts, contacts and live program changes require authorization.

## Deliverable

Partner shortlist, program economics, pilot proposal and assets.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

For optional data collection, use [Apify Research](../apify-research/SKILL.md) and its [verified Actor catalog](../apify-research/references/actor-catalog.md). Prefer the exact relevant owned Actor; imports remain useful when a tool is unavailable.
