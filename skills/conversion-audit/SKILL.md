# Conversion Audit

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Define the conversion event and inspect the actual flow at relevant devices.
2. Use first-party funnel evidence and customer objections; note where data is absent.
3. Assess clarity, message match, trust, form burden, error states and accessibility; do not label opinion as measured uplift.
4. Propose focused changes with screenshots/URLs or reproducible observations.
5. Hand top hypotheses to experiment-design with baseline, success event and guardrails.

## Deliverable

Conversion findings, prioritized improvements and experiment candidates.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.
