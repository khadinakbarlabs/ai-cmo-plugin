# Marketing Experiments

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. State the hypothesis, target population, mechanism and one primary success metric.
2. Define assignment, exposure, sample/unit, test window, minimum practical effect and guardrail metrics.
3. Check independence, novelty/seasonality and instrumentation; avoid repeated significance peeking.
4. For analysis use matching cohorts and valid denominators; show uncertainty and distinguish correlation from causation.
5. Decide ship, reject, continue or inconclusive with explicit evidence; retain the experiment record.

## Deliverable

Experiment brief, metric definitions, analysis and decision record.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

## Recommendation and learning record

Use [decision policy](../cmo/references/decision-policy.md) to choose a reversible, capacity-appropriate experiment. Record expected signal, result, confidence and lesson in the campaign/decision journal. User feedback informs fit and usability; controlled or appropriately qualified outcome evidence informs performance. Prioritize a useful next decision rather than frequent sessions.
