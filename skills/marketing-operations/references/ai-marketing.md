# AI Marketing

Apply the [shared operating contract](../../cmo/references/operating-contract.md). Use [Business Model Strategy](../../business-model-strategy/SKILL.md) to adapt goals and economics when context is missing.

Apply this reference through the owning skill; it is not a separate installed skill.

## Workflow

1. Define a useful marketing job and measurable quality/effort baseline before selecting automation; keep AI-search discovery distinct from AI-assisted production.
2. Map selected inputs, sources, recipient providers, confidentiality, access scope, cost and permitted outputs; minimize personal/client data and preserve business separation.
3. Choose available host capabilities or separately installed verified CLIs; inspect current schema/model rights, versions and authentication instead of inventing a native integration.
4. Build a reusable brief/prompt/workflow with brand context, evidence expectations, structured outputs, negative cases and human review gates for claims, likeness, originality and decisions.
5. Produce a reviewed pilot asset or workflow specification. Autonomous publishing, contact enrichment, budget changes and scheduled operation still require their concrete scope and supported execution.
6. Compare accuracy, usefulness, production time, revisions and cost against the baseline, keeping uncertainties and failures visible; do not promise fully autonomous CMO results or detector evasion.

## Deliverable

AI workflow brief, reusable prompts, reviewed pilot outputs, provider/data map and evaluation/rollout criteria.

Read the [working reference](ai-marketing-workflow.md) for relevant variants, fields and handoffs. For connected work, use [CLI capability checks](../../cli-integrations/references/tool-capabilities.md); no CLI or MCP is bundled.
