# AI Search Visibility

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Define a repeatable prompt/query set, locale, provider and observation window.
2. Use the exact owned AI search visibility Actor from the catalog; do not substitute a similarly named brand-monitor Actor.
3. Retain queries, response/source evidence, sampled platforms, timestamps and missing-result status.
4. Analyze brand mentions, citation accuracy, entity consistency and content gaps; avoid treating a visibility score as a universal ranking measure.
5. Recommend evidence-rich answers, clear entities and supported schema; compare future samples with the same methodology.

## Deliverable

Visibility baseline, citation evidence, gap priorities and repeatable monitoring specification.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

For optional data collection, use [Apify Research](../apify-research/SKILL.md) and its [verified Actor catalog](../apify-research/references/actor-catalog.md). Prefer the exact relevant owned Actor; imports remain useful when a tool is unavailable.
