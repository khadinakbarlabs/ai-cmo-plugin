# External tool capabilities

| Job | External integration | Contract | Disconnected output |
| --- | --- | --- | --- |
| Research | Apify CLI and exact owned Actors | [Actor selection and execution](../../apify-research/references/apify-cli.md) | Public evidence or CSV |
| Social scheduling/analytics | Postiz CLI | [Provider discovery and readback](../../social-publishing/references/postiz-cli.md) | Drafts/calendar |
| Email/newsletters | Resend CLI | [Email execution](resend-cli.md) | HTML/plain text/sequence |
| WordPress content | WP-CLI | [Draft/create/readback](wordpress-cli.md) | Markdown/HTML |
| Copy revision | Humanizer PRO standalone CLI | [Consent and word usage](humanizer-pro-cli.md) | Manual editing |
| Creative generation | Agent Media CLI | [Schema, run and output checks](agent-media-cli.md) | Script/storyboard/design brief |
| Paid ads | User's maintained advertising CLI | Verify installed account/create/change/spend contract | Campaign/import specification |
| Analytics/CRM | Supported reporting/provider CLI or first-party exports | Verify filters, timezone, attribution and supported operations | CSV/importable files |

These are external execution instructions, not bundled executables or native connectors. Read authoritative installed help and account-specific contracts before use. A documented route is not evidence that a user's tool is installed, authenticated or runtime-tested. Advertising and other unspecified providers remain capability-gated; never invent command names or substitute an HTTP call and describe it as a verified CLI. No MCP server is declared or required.
