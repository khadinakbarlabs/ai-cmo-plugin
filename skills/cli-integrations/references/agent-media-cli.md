# Media production handoff (compatibility route)

This reference path is retained for existing links. It does not authorize a media-generation integration.

AI CMO's directory edition does not launch AI video, audio, voice, music, avatar or general image generation. Do not install or invoke a media CLI, submit a generation request, check credits or start a paid sample through this route. Use [directory boundaries](../../cmo/references/directory-boundaries.md).

Deliver a reviewed script, storyboard, shot list, accessibility/caption specification and a handoff for a human creator/editor. If the user supplies an existing asset for review or authorized publishing, inspect that actual file and keep generation, review, upload and publication states separate. Design-only visual aids use an actually available permitted design workflow.
