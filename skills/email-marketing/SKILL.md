# Email and SMS Campaigns

Apply the [shared operating contract](../cmo/references/operating-contract.md) for evidence, local context and action scope.

## Workflow

1. Confirm audience consent/source, segment, offer, goal and provider capability.
2. Write subject/preheader, body and CTA variants with plain-text and mobile/accessibility considerations.
3. Review sender identity, authentication signals, suppression, unsubscribe, link tracking and frequency using available evidence.
4. Validate current provider templates/settings; do not promise inbox placement from a checklist.
5. Prepare the sending pack; sending and list changes require scoped authorization and verified external tools.

## Deliverable

Campaign pack, segmentation, deliverability findings and send checklist.

Use the [working reference](references/workflow.md) for covered variants, output fields and quality checks.

For account or production tools, use [CLI Integrations](../cli-integrations/SKILL.md) and its [tool capability guide](../cli-integrations/references/tool-capabilities.md). Do not assume an external CLI is installed or supports the intended action.
